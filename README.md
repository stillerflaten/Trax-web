# Trax

Nettside for iOS-appen Trax: support og personvernerklæring.

Norsk (`index.html`):
- Support: `/#support`
- Personvern: `/#personvern`

Engelsk (`en/index.html`):
- Support: `/en/#support`
- Privacy: `/en/#privacy`

De to sidene har samme stil. Endrer du tekst eller utseende på den ene, gjør det samme på den andre.
